# inbox/

Raw capture. Drop things here when you don't want to think about classification.

Mobile thoughts, half-formed ideas, links to read later, voice memos transcribed, screenshots — all of it.

## Conventions

- Filenames are casual. `2026-05-23-something.md` or `random-thought.md` both fine.
- Don't worry about formatting. Worry about getting it down.

## Processing

Every so often (or when this folder feels heavy), open items and decide:

- **A source?** → move to [`../sources/`](../sources/)
- **Your own thinking?** → move to [`../notes/`](../notes/) or a learning topic's `synthesis/`
- **A task or deliverable?** → move to [`../projects/`](../projects/) or an [`../areas/`](../areas/)
- **Just noise?** → delete

The `tend-topics` skill scans `inbox/` for items older than ~24h when proposing topic updates, so you get a nudge if things sit too long.
