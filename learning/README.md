# learning/

Structured topical study. One folder per topic, like notebooks per subject.

## Shape inside each topic

```
learning/<topic>/
  path.md            ← the syllabus / curriculum for this topic
  synthesis/         ← your evolving understanding (your "tutoring")
  practice/          ← flashcards, drills, self-tests, exercises
  projects/          ← build-to-learn projects (kata, exercises)
```

Optional `README.md` at the top of each topic doubles as that topic's index.

## When to start a new learning topic

When you find yourself wanting to *systematically* study something — not just collect notes, but follow a path, test your understanding, and build something to make it stick.

If you're just capturing scattered insights, those go in [`../notes/`](../notes/). A learning topic is a commitment.

## Learning projects vs. top-level projects

- `learning/<topic>/projects/` — build-to-learn. The artifact is incidental; the learning is the point.
- [`../projects/`](../projects/) — outcomes for the world. Shipping artifacts.

## Promotion

A synthesis note that proves cross-cutting (keeps getting linked from other topics, shows up in projects, etc.) earns the right to move to [`../notes/`](../notes/) — leave a link behind in the original location.
