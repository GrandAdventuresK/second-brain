# projects/

Active deliverables. Things you're shipping. Each project has an outcome and (ideally) a rough deadline.

Examples: launching a feature, writing a post, running an event, learning a thing by Friday.

## Project vs. learning project

- Top-level `projects/` — outcomes for the world. Shipping artifacts.
- `learning/<topic>/projects/` — build-to-learn. The artifact is incidental; the learning is the point.

Same word, different intent.

## Shape

Each project is a folder. Inside:

- `README.md` — what, why, by when, current status
- supporting notes, drafts, references

When a project is done, decide: archive (one day), delete, or convert into an [`../areas/`](../areas/) entry if it's becoming ongoing.
