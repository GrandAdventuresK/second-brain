# Curriculum

The strategic layer the [block ritual](block-ritual.md) operates within. Built for mastery, not credentials. Designed to evolve.

This is one user's curriculum, not vault infrastructure. If you're not me, treat it as an example of what a self-designed graduate-level program looks like inside this system.

## The unifying question

Lives in [`through-line.md`](through-line.md) — kept in its own file because the question itself is expected to move as the work matures. The curriculum's job is to press on that question from three sides until I have an answer worth shipping.

## Three paths as lenses

| Path | Layer of the question |
| --- | --- |
| [`learning/leadership-and-identity/`](learning/leadership-and-identity/) | The **be** — who must I become? |
| [`learning/ai-and-emerging-tech/`](learning/ai-and-emerging-tech/) | The **know** — what is the substrate? |

Three is the cap. Domains not on a path stay ambient — they flow through `inbox/` and `sources/` and may earn a `notes/` atom, but get no structured path until a slot opens. A slot opens when a path matures: its synthesis is teachable *and* it has driven a shipped change at Grand Adventures.

## Three phases, criterion-based

No calendar deadlines. Phases advance when their criterion is met. Slower progress beats false graduation.

### Phase 1 — Foundations

**Criterion:** I can teach each path's foundation to a peer in 30 minutes, without notes.
**Work:** one core text per path, pressed deeply. Build working vocabulary and the basic shape of the domain.
**Output:** a `synthesis/` per path that holds the foundation in my own words.

### Phase 2 — Integration

**Criterion:** at least one documented change shipped at Grand Adventures that draws on two or more paths integrated.
**Work:** modules that intentionally combine paths — *AI + Identity*, *Systems + Org*, *Leadership in an AI-shaped firm*. Cross-cutting questions become atomic notes and `topics/` pages.
**Output:** integration essays plus applied changes in `areas/` and in the company itself.

### Phase 3 — Specialization

**Criterion:** original work shipped — a framework, methodology, or extended argument that didn't exist before I wrote it.
**Work:** narrow, deep, my cut of the through-line.
**Output:** the dissertation. A Substack series, a book, an internal methodology Grand Adventures operates by, or a public talk that crystallizes the whole arc.

## Five modes of work

The block ritual is one mode — the default. Different work needs different shapes. Escalate from lecture-block when the work calls for it.

| Mode | What it is | Where it lands |
| --- | --- | --- |
| **Lecture-block** | Press one source into atomic notes. The default. | `notes/` and `learning/<path>/synthesis/` |
| **Seminar-block** | Hold 2–3 sources in tension; write the synthesis essay. | `learning/<path>/synthesis/` |
| **Lab-block** | Apply hands-on. Build a tool, run a team experiment. | `learning/<path>/projects/` |
| **Problem-set-block** | Take a real Grand Adventures decision; solve it with the framework you're studying; write up what you learned. | `learning/<path>/practice/` or `areas/` |
| **Comp paper** | Quarterly. 1500–2500 words shipped externally. Non-negotiable. | Drafted in `learning/<path>/`; published outside |

## Forcing functions

Three, layered. Without external stakes this becomes a reading list.

1. **Teach to team.** Once per module: a 30-minute internal talk that turns the synthesis into something the team can use. If you can't teach it, you don't know it.
2. **Apply at Grand Adventures.** Every module ends with a documented change in `areas/` or in the company. The company is the lab.
3. **Quarterly public writing.** One comp paper per quarter, shipped externally — Substack, LinkedIn, a memo to a real audience. External stakes against your articulation.

Hit at least one forcing function per module. All three per quarter.

## When to revisit this file

- End of Phase 1, minimum.
- Sooner if the through-line shifts meaningfully.
- Sooner if a forcing function isn't holding.
- Sooner if a fourth path is fighting to be born — pressure to add a path usually means an existing one has matured, not that the cap is wrong.
